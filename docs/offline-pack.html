חבילת Stand-alone ל-Flight Planner

מחשב א' עם אינטרנט מוריד לדיסק נייד. מחשב ב' בלי רשת מתקין מהדיסק ומריץ.

מה שחייב להיות בתיקייה

flight-planner-offline/
  main.py
  web_app.py
  requirements.txt
  python-installer.exe
  vc_redist.x64.exe
  wheels/
  srtm/
  map_tiles/
  flight-planner-config.json

אין צורך להעתיק תיקיות numpy מוכנות. pip בונה אותן מה-wheels על מחשב ב'.

1. Python

הורד מתקין Windows 64-bit (3.11/3.12) מ- python.org/downloads/windows ושמור כ-python-installer.exe. גם vc_redist.x64.exe.

2. pip wheels — רק במחשב עם רשת

mkdir flight-planner-offline\wheels flight-planner-offline\srtm
pip download -r requirements.txt -d flight-planner-offline\wheels

זה מוריד את streamlit, numpy, pillow, folium, SRTM.py וכל התלויות. HTML לא יכול להחליף את זה מהדפדפן.

3. DTM לישראל + לבנון

לחץ ושמור ל-srtm/. אם Africa מחזיר 404 — נסה Eurasia.

4. מפה

Folium מושך OSM מהרשת. בלי שינוי קוד האנליזה תעבוד עם DTM מקומי; המפה עלולה להיות אפורה. אריחי מפה: Mobile Atlas Creator / SAS.Planet, זום 6-12, ל-map_tiles.

5. התקנה במחשב הסגור

python-installer.exe     (Add python.exe to PATH)
cd flight-planner-offline
pip install --no-index --find-links=wheels -r requirements.txt
streamlit run web_app.py

נפתח http://localhost:8501 — זה לא אינטרנט. אם SRTM מבקש הורדה: העתק את srtm גם ל-%USERPROFILE%\.cache\srtm
